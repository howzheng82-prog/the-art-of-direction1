# The Art of Direction

手机横屏音乐指挥节奏游戏原型。  
用滑动、点击和长按模拟指挥动作，完成节拍、Cue 与 Dynamics 事件。

## 功能

- 横屏布局
- 7 首曲目列表
- 2.5D 舞台视觉
- 双手与指挥棒
- 箭头方向指挥
- Cue / Dynamics 原型
- 评分、连击、准确率
- 暂停菜单
- 结果页面
- 教学状态保存
